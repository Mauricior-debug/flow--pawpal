# PawPal

A native app for dog owners to track walks, meals, vet visits, and training streaks. Biscuit the corgi is on every screen. Warm cream, deep teal, and sunny orange come from the approved screen designs.

## Screens

- Welcome — Continue with Apple or email
- Home — today's walk ring, next meal, streak
- Walk — live map, timer, distance, pause and stop
- Health — vet visits, vaccines, weight chart
- Training — daily trick lesson, tricks, streak calendar
- Profile — dog photo, breed, age, settings

Sheets: email sign-in, meal, vet visit, vaccine, weight, record detail, vet reminder, lesson, trick practice, edit profile, notifications, preferences, delete account, walk summary, and a walk moment.

## Run

```bash
npm install
npx expo start
```

Expo SDK 58. Open it in Expo Go. `runtimeVersion` is `58.0.0`.
